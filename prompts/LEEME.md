# prompts

Los prompts como archivos de texto, versionados aparte del código.

- `style-spec.md` — las reglas duras destiladas del canon: longitud de frase, densidad léxica,
  estructura obligatoria, qué nunca hacer. Es el activo principal; se corrige a mano.
- `constructor-lectura.txt` — el prompt de generación: style spec + ejemplos elegidos + la ficha.
- `versiones/` — copias de prompts anteriores, para poder comparar salidas.
